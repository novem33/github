# HTML 範例專案

這是一個簡單的 HTML 練習專案，目前包含一個可直接用瀏覽器開啟的範例頁面。

## 專案內容

- `範例.html`：基本 HTML 範例頁面
- `README.md`：專案說明文件

## 功能說明

`範例.html` 內含：

- 基本 HTML5 結構
- 簡單的版面與樣式
- 一個可點擊按鈕
- 按鈕點擊後會跳出提示視窗

## 使用方式

1. 下載或複製此專案
2. 直接用瀏覽器開啟 `範例.html`
3. 即可查看頁面效果

## 適合用途

- HTML 初學者練習
- 當作靜態頁面起始模板
- 測試基本排版與 JavaScript 互動
